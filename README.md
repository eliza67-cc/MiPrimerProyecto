# Código Creativo ♡
Blog escolar de programación con diseño coquette en HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura del sitio
- `style.css`: estilos adaptables a celular
- `script.js`: artículos interactivos

## Uso
Abre `index.html` en tu navegador. Las fotografías se cargan desde Unsplash y requieren internet.

## Subir a GitHub
1. Crea un repositorio público.
2. Sube los tres archivos juntos en la raíz.
3. Ve a Settings → Pages y activa Deploy from a branch, `main`, `/ (root)`.
4. En Settings → Collaborators invita a tres compañeros; deberán aceptar.

**Nota:** Esta es una página web para GitHub, no un tema instalable de Blogger. Para la otra actividad crea tu blog directamente en blogger.com y publica el contenido de los artículos.
